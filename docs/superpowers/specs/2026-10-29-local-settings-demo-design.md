# 로그인 없이 설정에서 기기 데모 시작

문제: DEBUG -tabs는 인증 화면만 건너뛴다. 설정의 서버 데모 버튼은 인증과 기존 그래프가 필요해, 미로그인 상태에서는 자료를 넣지 못하면서 그래프 없음 문구를 보인다.
사용자가 로그인 없이 앱을 열고 설정의 데모를 활용하도록 요청했다. 미로그인 설정 버튼과 로그인 화면의 개발용 진입 버튼에서 기기 데모를 활성화한다. 기존 ReportSamples/TimelineSamples의 합성 그래프·기록을 재사용하며 실제 서버 계정 자료와 구분한다.

- DEBUG에만 제공한다. 인증된 서버 데모 경로는 유지한다. JWT나 서버 인증을 우회하지 않는다.
- 기기 데모 여부만 보존한다. 데모의 기록/설정/대기 사진은 기존 격리된 예시 저장소를 쓰며 재실행하면 초기 예시로 돌아간다. 실제 기록, 설정, 사진, 위젯은 변경하지 않는다.
- 설정 버튼으로 활성화한 즉시 홈·리포트·기록이 같은 데모 소스를 사용한다. 기존 CLI 예시도 계속 동작한다.
- 로그인·온보딩에도 DEBUG 진입 버튼을 제공한다. 기기 데모임과 서버 미저장을 표시하며 설정에서 종료할 수 있다.
- 단위 회귀는 모드 전환과 영속 활성 여부, UI 회귀는 -tabs만으로 시작→설정 버튼→그래프/기록 표시→종료를 검증한다. Release 컴파일로 DEBUG 코드 격리도 확인한다.
- 5단계 데이터 보존 작업은 중단된 기존 체크아웃에 보존한다. 이 변경은 PR78 기준 별도 브랜치이며 push/merge/deploy하지 않는다.
