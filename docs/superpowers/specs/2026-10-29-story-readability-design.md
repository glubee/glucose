# 하루 이야기 가독성 정리

요청: 하루 이야기가 한 문단으로 이어져 한눈에 읽기 어렵다.

- 기존 story 배열을 공백으로 합치던 표시를 문장별 행으로 구분한다. 작은 점과 행 간 여백으로 읽을 위치를 구별한다.
- 숫자·시각을 굵게 표시하되 서버 원문의 글자와 수치는 변경하지 않는다. 자연어 내용에 따라 임의의 의료/사건 분류를 붙이지 않는다.
- 근거와 긴 안내는 ‘근거 및 안내’에서 펼쳐 본다. 숫자 카드/그래프 순서는 유지한다.
- 같은 컴포넌트를 사용하는 주간 이야기에도 같은 서식이 적용된다. 주간 집계/API는 변경하지 않는다.
- 이번 변경은 되돌릴 수 있는 표시 서식 변경이므로 별도 구현 복제 테스트를 추가하지 않고, 기존 이야기 순서/닫기 및 글 위 드래그 회귀와 앱·위젯 빌드로 확인한다.

검증 결과:
- 기존 UI 검사 2건 통과: 이야기와 수치의 표시 순서/미리보기 닫기, 이야기 위에서 터치로 스크롤하기.
- iOS Simulator 대상 앱·위젯 빌드 성공.
- iPhone 17 Pro 시뮬레이터에서 문장별 여백, 숫자·시각 강조와 근거/안내 펼치기·접기를 직접 확인했다.
- 물리 마우스·트랙패드 스크롤의 기존 확인 한계는 이번 서식 변경으로 해결되었다고 주장하지 않는다.
