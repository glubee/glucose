# 그래프 안에서 기록 확인하기

사용자는 홈/리포트 그래프의 겹친 아이콘, 밀린 시간 글자, 인슐린 아이콘 누락을 지적했다. 같은 화면에서 확대·축소하고 아이콘 위 팝업과 해당 시각 점선 강조로 내용을 확인하는 안을 요청했으며, 리포트에서 손가락/마우스 드래그로 아래 내용을 볼 수 없는 현상도 함께 수정하도록 요청했다.

## 선택한 방향
- 아이콘 근처 팝업(사용자 선호): 기록과 곡선의 위치 관계 유지. 경계에서는 화면 안으로 위치를 조정한다.
- 대안인 아래 고정 설명 영역은 작은 홈 화면을 계속 차지하므로 사용하지 않는다.
- 새 창으로 확인을 시작하는 기존 방식은 사진 확대·명시적인 기록 상세 이동에만 남긴다.
- 팝업은 조회용, 수정은 기록 상세로 연결한다(응답 없는 선택 사항은 앞서 권장한 기본값 적용).

## 동작
- 식사·간식·대응·인슐린 아이콘을 같은 표시 모델로 만든다. 한 위치에 가까운 기록은 화면 폭/확대 배율에 따라 ‘기록 N건’으로 묶으며, 같은 시각 기록도 누락하지 않는다.
- 아이콘 선택: 작은 팝업에 정확한 시각과 종류·음식/인슐린 사실을 표시한다. 묶음 항목 선택 시 해당 기록 점선을 강조하고 다른 선은 옅게 한다. 빈 곳/같은 아이콘/닫기로 해제한다.
- 하루/12/6/3시간 버튼, 두 손가락 확대·축소와 가로 이동을 현재 그래프 안에서 제공한다. 세로 화면 스크롤은 방해하지 않는다.
- 결측은 연결하지 않는다. 빈 구간에는 ‘데이터 없음’을 표시하며, 그 시각의 이벤트는 그대로 확인할 수 있다.
- 시간 글자는 실제 시간 눈금 위에 가운데 정렬한다. 예시 요약과 곡선의 수치 불일치를 정리한다.
- 홈/일일 리포트 공통, 하루 마무리의 작은 그래프는 기본 표시 유지. 기존 확대 화면과 사진 보기/실제 상세 조회는 재사용한다.

## 검증/제약
- iOS17+, SwiftUI/Charts, 새 외부 의존성/서버 변경 없음. 인슐린 조언/새 의료 해석 없음.
- 실제 개인정보·사진 URL 로그 금지. 예시는 합성 자료이며 수정/저장 차단.
- 실제 탭 화면에서 텍스트 위/여백/그래프 위 세로 드래그, 축소→확대→하루 복귀, 묶음/개별 선택·해제·경계·날짜 변경을 확인한다.
- 스크롤은 먼저 재현한다. 앱에서는 정상이고 Simulator 입력만 문제라면 그 근거와 조작 방법을 구분해서 보고한다.

## 구현 시 결정
- 기록 ID 없는 리포트이므로, 명시적 상세 이동 시 기존 음식 resolver와 같은 조건으로 인슐린도 시각·종류·단위를 대조한다. 중복/검색 미완료면 임의의 기록을 고르지 않는다.
- 팝업은 네이티브 말풍선으로 유지하며, 화면 높이가 짧아도 사진/상세 버튼에 접근하도록 내용 전체를 스크롤한다.
- 팝업을 닫아도 마지막으로 선택한 기록 시각을 확대 초점으로 기억한다. 직접 좌우 이동하면 선택 초점은 해제하고 현재 구간 중심을 유지한다.
- 24시간 상태에서 공간이 부족하면 다른 종류도 ‘기록 N건’으로 묶고, 팝업에서는 종류 아이콘과 정확한 시각을 각 항목에 표시한다. 기록 수는 식사 횟수를 의미하지 않는다.
- 예시의 평균·최저·최고·근거 수와 관찰 근거는 실제 합성 곡선에서 계산한다. 식전 기준값은 식후 관측 수에 포함하지 않는다.
