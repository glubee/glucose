# iOS 디자인 v4 적용 계획

> 기준: Figma `Glucose_design-탬플릿` v4 캔버스 PNG(2026-10-27 내보낸 것, 저장소 밖 보관).
> 이미지에서 읽은 값이라 색·크기는 **추정치**다. 픽셀 일치보다 토큰 일관성을 우선한다.
> v4를 그대로 옮기지 않고, 정책·데이터와 맞지 않는 부분은 아래 "개선 제안"대로 고친다.

## 0. 핵심 사용 흐름 (2026-10-27 Dave)
v4 화면보다 이 흐름이 우선이다.

1. **그때그때 원탭 기록 (위젯)**
   - 사진 위젯 → 앱이 **카메라 화면으로 바로** 열린다 → 찍으면 끝. 업로드·인식은 뒤에서 하고, 음식 확인 화면은 띄우지 않는다.
   - 인슐린 위젯 → 앱이 **인슐린 투여 확인 화면으로 바로** 열린다 → 제품·단위·지금 시각이 채워져 있고 "투여 확인" 한 번으로 저장.
   - 앱 안에서 기록하는 기존 흐름(v4 홈 → 음식/인슐린 기록)도 그대로 둔다.
2. **하루 끝에 완성 (하루 마무리)**
   - 리브레 일일 그래프 올리기 → 낮에 찍은 사진의 인식 결과 확인·수정 → 빠진 음식·인슐린 추가 → 완성된 일일 그래프 확인.
   - 저녁 알림(기본 21:00, 로컬 알림)으로 시작한다.

### 위젯 구성 (iOS 17, 앱 열기 방식)
| 위치 | 종류 | 동작 |
|---|---|---|
| 홈 화면 | 중간(medium) | 버튼 2개: 사진 찍기 / 인슐린 기록 (각각 `Link`) |
| 홈 화면 | 작은(small) 2종 | 사진 찍기 하나, 인슐린 기록 하나 (`widgetURL`, small은 탭 영역이 하나뿐) |
| 잠금 화면 | 원형(accessoryCircular) 2종 | 위와 같음 |
| 단축어·Siri·동작 버튼 | App Shortcuts(AppIntent, 앱 열기) | 같은 화면으로 이동 |

- 딥링크: `glubee://capture`, `glubee://insulin`. `onOpenURL`로 받아 바로 해당 화면을 띄운다. 로그인 안 된 상태면 로그인 후 이어서 연다.
- 위젯에서 서버 호출·토큰 공유는 하지 않는다. 연속일·글루비 감정 표시용으로 App Group 공용 저장소만 읽는다(W5부터).
- iOS 18 제어 센터·잠금 화면 컨트롤은 나중에 추가한다(iOS 18 이상 기기에서만).

### 인슐린 투여 확인 화면 규칙
- 제품·단위는 **사용자가 설정에 직접 넣은 "평소 인슐린" 값**으로만 미리 채운다. 앱이 계산하거나 추천하지 않는다. 처음엔 빈칸.
- 화면에 "내가 입력한 평소 값이에요. 다르면 고쳐주세요." 같은 안내를 둔다. 시각은 지금, 바꿀 수 있다.
- "투여 확인"을 누르면 바로 `POST /v1/insulin-events` (기존 API 그대로).

### 빠른 사진 기록 규칙
- 촬영 시각을 기록 시각으로 쓴다(업로드가 늦어도 시각은 촬영 기준).
- 찍은 사진은 기기의 "확인 대기" 목록에 넣고 업로드·인식을 진행한다. 네트워크 실패 시 앱이 다시 열릴 때 재시도.
- 기록(intake)은 하루 마무리에서 사용자가 확인할 때 만든다(지금 API 그대로). 서버에 "확인 대기 사진 목록" API가 없어서 대기 목록은 처음엔 기기에만 있다 → 나중에 `GET /v1/photos?unconfirmed` 추가 검토.

## 0-1. 계속 쓰게 만드는 장치 (연속 완성일 · 알림 · 글루비 감정)
듀오링고처럼 연속 기록과 마스코트 반응으로 동기를 준다. 목표는 "매일 그래프 완성".

### 연속 완성일 (스트릭)
- **완성한 날** = 그날 하루 마무리를 끝낸 날(그래프 분석 성공 + "오늘 정리 마치기"). 연속 완성일 수를 홈·위젯에 크게 보여준다.
- **다음 날 정오까지 유예**: 리브레 하루 그래프는 자정이 지나야 다 차므로, 어제 마무리는 다음 날 12:00까지 해도 인정. 아침에 그래프를 다시 올리면 덮어쓰기(기존 규칙).
- **꿀단지(스트릭 보호)**: 7일 연속마다 1개(최대 2개). 빠진 날에 자동으로 1개 써서 연속을 지킨다. 센서 교체·그래프 인식 실패 같은 날을 위한 장치.
- **벌집 칸**: 한 주 7칸(v4 하루 마무리의 육각형). 완성한 날은 꿀이 차고, 꿀단지 쓴 날은 다른 표시.
- **기념일**: 3·7·14·30·50·100일에 축하 화면(글루비 축하 동작).

### 글루비 감정 (기록 행동에만 반응)
| 상태 | 언제 | 예시 문구 |
|---|---|---|
| 신남 | 기록 직후, 마무리 완료 | "찰칵! 잘 남겼어요." |
| 평온 | 오늘 기록이 있음 | "오늘도 같이 모으는 중이에요." |
| 보채기 | 오늘 아직 기록 없음(점심 이후) | "심심해요… 사진 한 장만 보여주세요!" |
| 조마조마 | 밤인데 마무리 안 함, 연속 끊기기 직전 | "연속 12일이 오늘 밤에 사라질지도 몰라요!" |
| 화남(귀엽게) | 2~3일 앱 활동 없음 | "흥! 꿀단지 혼자 지키고 있었다고요." |
| 시무룩·잠듦 | 일주일 이상 없음 | "기다리다 잠들었어요… 돌아오면 깨워주세요." |
| 축하 | 기념일, 꿀단지 획득 | "30일 연속! 벌집이 꽉 찼어요." |

홈 상단 마스코트와 위젯의 글루비가 이 상태에 맞춰 바뀐다.

### 지켜야 할 선 (건강 앱이라 중요)
- 글루비는 **기록을 했는지 안 했는지에만** 반응한다. 혈당 수치, 저혈당·고혈당, 인슐린 용량, 먹은 음식에는 **화내지도 칭찬하지도 않는다**("혈당 좋았어요!"도 금지).
- 화내기·보채기는 귀여운 투정까지만. 비난·죄책감·건강 위협 문구("이러다 큰일 나요") 금지.
- 저혈당 처치 기록 뒤 2시간은 보채는 알림을 보내지 않는다.
- 알림 문구에 혈당값·음식·인슐린 내용을 넣지 않는다(잠금 화면에 보임).
- 말투는 하나로 통일한다(선택 없음, 2026-10-27 Dave). **존댓말 해요체**("~했어요", "~이네요"). 보채기·화남까지 쓰되 귀여운 투정 수준. 알림은 설정에서 쉽게 끈다.

### 알림 (로컬 알림, 서버 푸시 없이)
앱을 열거나 기록할 때마다 앞으로 7일치 알림을 **지우고 다시 예약**한다. 활동이 없으면 이미 예약된 알림이 차례로 나간다.

| 언제 | 조건 | 감정 |
|---|---|---|
| 13:00 | 오늘 기록 0건 | 보채기 |
| 21:00 | 오늘 마무리 안 함 | 평온("하루 마무리 할 시간") |
| 22:30 | 마무리 안 함 + 연속 1일 이상 | 조마조마 |
| 다음 날 10:00 | 어제 마무리 안 함(유예 중) | 조마조마("정오까지 어제 그래프 완성 가능") |
| 활동 없음 1·2·3·7일째 저녁 | 앱 활동 없음 | 시무룩 → 보채기 → 화남 → 잠듦, 7일 뒤엔 멈춤 |

- 하루 최대 2개, 23:00~08:00 조용한 시간. 시각은 설정에서 바꿀 수 있다.
- 같은 상태라도 문구 여러 개 중 하나를 골라 지루하지 않게 한다(문구 묶음은 앱 안 JSON).
- 알림 권한은 첫 기록을 마친 뒤 "알림으로 챙겨드릴까요?" 화면에서 요청한다(첫 실행 때 바로 묻지 않는다).

### 저장
- 처음엔 기기에 저장(App Group 공용 저장소 — 위젯도 같은 값을 읽어 연속일·감정을 표시). 마지막 활동 시각, 날짜별 완성 여부, 꿀단지 개수.
- B단계에서 서버 `day_close` 테이블로 옮겨 기기를 바꿔도 연속일이 유지되게 한다.

### 필요한 마스코트 동작 (디자이너 요청)
기존 13종에 더해: **화남, 보채기(팔 흔들며 조르기), 조마조마, 시무룩, 잠듦, 축하(폭죽)**. 위젯용 작은 얼굴 버전도 상태별로.

## 0-2. 첫 설정 (글루비와 대화하는 온보딩)
레퍼런스: Gentler Streak 온보딩(캐릭터가 자기소개하며 설정을 이끄는 방식). **구성·분위기만 참고**하고, 캐릭터·그림·문구는 글루비 것으로 만든다.

- 한 화면에 질문 하나. 위쪽은 글루비(크게), 아래는 큰 제목 + 선택지 + 하단 버튼 하나.
- 고를 때마다 글루비가 **반응**한다(동작 바뀜 + 짧은 말 + 가벼운 햅틱). 글루비를 탭하면 꿈틀거린다.
- 모든 단계는 "나중에 할게요"로 건너뛸 수 있고, 설정에서 다시 바꿀 수 있다.

| 단계 | 글루비 | 받는 것 | 반응 예시 |
|---|---|---|---|
| 1 | 날아 들어오며 손 흔들기 | — | "안녕하세요! 저는 글루비예요. 하루를 같이 모으는 꿀벌이에요." |
| 2 | 고개 갸웃 | 부를 이름(별명) | "민지님! 예쁜 이름이네요." |
| 3 | 카메라 들기 | 이 앱 쓰는 법 3컷: 찍기 → 인슐린 → 하루 끝에 그래프 | "먹을 때 한 번, 맞을 때 한 번. 나머지는 밤에 같이 해요." |
| 4 | 노트 들기 | 평소 쓰는 인슐린(제품명, 평소 단위) — 여러 개 가능 | "기억해둘게요. 맞을 때 바로 채워드릴게요." (값은 사용자가 넣은 그대로) |
| 5 | 시계 보기 | 하루 마무리 시각(기본 21:00) | "그 시간에 꿀통 들고 찾아갈게요." |
| 6 | 두 팔 응원 | 알림 허용(시스템 권한 창) | 허용: "약속해요!" / 거절: "괜찮아요. 설정에서 언제든 불러주세요." |
| 7 | 위젯 가리키기 | 위젯 추가 방법 안내(홈 화면 길게 누르기 → + → 글루비) | "여기 저를 붙여두면 한 번에 기록돼요." |
| 8 | 꿀단지 안기 | Sign in with Apple | "기록을 안전하게 보관할게요." → 홈으로 |

- **로그인은 마지막**: 지금은 앱을 켜자마자 로그인 화면이다(`RootView`). 먼저 글루비와 친해지고 마지막에 로그인한다. 설정 값은 기기에 저장해 두고, 프로필 API가 생기면(B단계) 서버로 옮긴다.
- 알림 권한은 0-1장에서 "첫 기록 뒤"로 정했지만, 온보딩 6단계에서 맥락과 함께 먼저 묻는다. 거절하면 첫 하루 마무리 뒤 한 번 더 권한다.
- 목표 혈당 범위는 묻지 않는다(기본 70–180 표시, 의료진과 정한 값이 있으면 설정에서 바꿈). 첫 설정에서 의학적인 결정을 요구하지 않는다.

### 쉬어가기 (상태 설정)
레퍼런스의 "Set Status"처럼, 기록을 못 하는 날을 사용자가 미리 알린다.
- **쉬는 중 / 몸이 안 좋아요 / 센서 없음(교체·분실)** 중 선택 → 그 기간엔 연속일이 **끊기지도 늘지도 않고**, 보채는 알림도 멈춘다. 글루비는 "쉬어가는 중" 동작.
- 꿀단지(0-1장)는 미리 못 알린 날을 위한 것, 쉬어가기는 미리 아는 날을 위한 것.
- 건강 앱이라 "아픈데도 기록하라고 보채는" 상황을 막는 장치다.

### 월간 돌아보기
레퍼런스의 Monthly Recap처럼 큰 숫자 하나 + 글루비 + 한 줄.
- "10월에 그래프를 **22일** 완성했어요. (9월: 5일)" + 날짜별 완성 점 그래프 + 축하/응원 동작.
- 숫자는 **완성한 날·기록 건수**만. 혈당 평균·범위 같은 수치를 칭찬이나 평가 문구와 묶지 않는다.

## 1. 디자인 토큰 (추정)

### 스타일 원칙 (심플·깔끔)
레퍼런스(Gentler Streak)처럼 정리한다. v4의 색은 유지하고 밀도를 줄인다.
- 배경은 거의 흰색, 카드 테두리·그림자는 최소. 구분은 여백과 얇은 선으로.
- 화면마다 **핵심 숫자 하나를 크게**(예: 연속 12일, 22일 완성). 보조 정보는 작은 회색 글씨.
- 강조색(brand 노랑)은 화면당 한 곳(주 버튼 또는 선택 상태)에만.
- 글루비는 장식이 아니라 화면의 주인공으로 크게, 대신 한 화면에 하나만.
- 작은 대문자 섹션 라벨(예: "이번 달", "기록") + 큰 제목 + 짧은 설명의 3단 구조를 반복.
- 애니메이션은 짧은 스프링과 글루비 동작 전환만. 과한 효과는 쓰지 않는다.

### 색
| 토큰 | 라이트 | 용도 |
|---|---|---|
| `brand` | `#F6CF52` | 주 버튼, 선택된 칩·탭, 날짜 선택 |
| `brandSoft` | `#FFF7D9` | 선택 카드 배경, 합계 카드, 말풍선(노랑) |
| `brandSofter` | `#FFF2C2` | 선택된 칩/세그먼트 배경 |
| `mint` | `#E6F7EE` | 목표 범위 밴드(70–180), 글루비 말풍선(초록) |
| `mintStrong` | `#2E7D57` (추정) | 링크·보조 강조 텍스트("하루 혈당 흐름 보기", "기록 보기") |
| `insulinSoft` | `#F7F0FB` | 인슐린 타임라인 카드 배경 |
| `insulin` | `#9B4DCA` (추정) | 인슐린 아이콘·라벨 |
| `alert` | `#E5534B` (추정) | 그래프 범위 밖 구간, 고혈당 점 |
| `textPrimary` | `#1E242A` | 본문·제목 |
| `textSecondary` | `#6B7278` (추정) | 설명·캡션 |
| `surface` | `#FFFFFF` | 카드·화면 배경 |
| `surfaceMuted` | `#F0F2F3` | 입력 필드, 비활성 버튼("오늘 정리 마치기") |
| `line` | `#E8EAEB` | 구분선, 테두리 버튼 |

다크 모드는 v4에 없다 → 같은 역할로 다크 값을 새로 정한다(brand는 유지, soft 계열은 채도 낮춘 어두운 톤).

### 글꼴·간격·모양
- 글꼴: 시스템(SF Pro / Apple SD Gothic Neo). 홈·말풍선의 굵은 둥근 제목은 **Dynamic Type 스타일**로 대응(`.title2.bold()` 등). 커스텀 폰트는 라이선스 확인 전까지 쓰지 않는다.
- 화면 좌우 여백 20, 카드 안 여백 16, 카드 간격 12.
- 라운드: 카드 16, 버튼(캡슐) 전체 둥글게, 칩 캡슐, 시트 상단 24.
- 주 버튼: 높이 52, `brand` 배경 + `textPrimary` 글자(흰 글자 금지 — 대비 부족).

### 마스코트(글루비)
- 기존 5동작(인사·기록 보기·빠진 기록·시간 선택·저장 완료 등) + 새 8동작(끄덕이기·고민·엄지·응원·카메라·돋보기·쉬기·꿀단지).
- **개별 PNG(투명 배경, @2x/@3x) 또는 PDF로 다시 내보내 받아야 한다.** 캔버스 캡처에서 잘라 쓰지 않는다.
- 규칙(v4 메모 그대로): 색 필터·과한 확대·회전 금지, 오류·미기록 상태를 성공 표정으로 표현하지 않기.

## 4. 개선 제안 (v4에서 바꿀 것)
1. **kcal·영양정보 표시 빼기.** 계약상 AI는 "무엇을 몇 개"까지만 내고 영양 숫자는 응답에 없다. 사진 추정 kcal은 오차가 크고, 이 앱의 목적(혈당 변화 확인)과도 거리가 있다. 항목은 `이름 · 개수 단위`로, 합계 카드는 "N가지 음식"으로 바꾼다. 직접 등록의 영양 입력칸도 빼고 이름·단위만 받는다.
2. **혈당 그래프 업로드를 홈에 노출.** 모든 리포트·리뷰가 그래프에 달려 있는데 설정 안에 숨어 있다. 오늘 그래프가 없으면 홈 차트 자리에 "리브레 그래프 올리기" 빈 상태 카드를 둔다.
3. **끊긴 구간은 잇지 않기.** v4 차트(홈·리뷰·리포트)는 매끈한 곡선이다. 실제로는 `MISSING` 구간을 비우고, 점 사이만 직선으로 잇는다(곡선 보간 금지). 기존 `GlucoseDayChart` 규칙 유지.
4. **"글루비의 제안"은 서버 `education_card` 고정 문구만.** "포도당 정제·주스 준비" 같은 문구는 일반 교육 정보로만, 출처와 함께, 의료인 검토 문구로 표시한다. 앱에서 문장을 만들지 않고, 용량·양 추천은 넣지 않는다.
5. **저혈당 처치 기록을 빠르게.** 지금은 음식 기록 → 촬영 → 확인 → 맨 아래 칩에서 "저혈당 대응"을 고른다. 홈 음식 기록 시트에 "저혈당 대응으로 기록" 항목을 추가해 상황을 미리 정하고 들어간다.
6. **탭 바는 기본 `TabView` + 색 토큰.** 떠 있는 캡슐 탭 바는 직접 만들면 접근성·안전 영역 처리가 늘어난다. iOS 기본 탭 바에 brand 색만 입힌다(원하면 나중에 교체).
7. **회색 작은 글씨 대비 확인.** 캡션(`textSecondary`)은 흰 배경에서 4.5:1 이상으로 맞춘다. Dynamic Type 큰 글씨에서 홈 제목과 마스코트가 겹치지 않게 마스코트를 줄이거나 아래로 보낸다.
8. **이름 표시.** 프로필 API가 없으므로 처음엔 이름 없이("오늘의 흐름을 함께 볼까요?") 쓰고, 설정에서 별명을 입력하면 기기에 저장해 쓴다.
