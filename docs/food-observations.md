# 음식 기록 기반 혈당 관찰

음식명·수량·섭취 시각을 그 뒤 그래프에서 읽힌 값과 연결한다. 계산과 문장은 서버에서 결정한다. 음식 이름이나 개인 관찰값을 외부 AI에 보내지 않는다. 기존 AI 문장화는 전체 기록 요약을 담당하고, 음식별 관찰은 별도 영역에 자동 표시한다.

## API와 표시

- `GET /v1/reports/daily/{date}/food-observations`
- `GET /v1/reports/weekly/{date}/food-observations`

JWT의 사용자 ID로 해당 사용자의 현재 음식·인슐린·그래프 기록만 조회한다. 주간은 한국 시간 월~일이다. 일일 화면에는 음식명·시각·기록 직전 값·이후 읽힌 최고·최고와 직전 값의 차이·구간 끝 값·근거 상태를 표시한다. 주간 화면에는 같은 음식 조합과 분량으로 등록된 기록의 반복 관찰 및 원래 기록을 표시한다.

음식명이 여러 개인 기록은 한 조합으로 취급한다. 예를 들어 김밥+우유의 결과를 김밥 단독 결과로 합치지 않는다. 맥락(식사/간식/처치/술)과 기록된 수량·단위도 구분한다. 분량 미상은 미상으로 보존하며 같은 실제 분량으로 간주하지 않는다.

## 관찰 규칙

- 사용자가 저장한 맥락을 그대로 사용한다. 기존 자동 처치 분류를 변경하거나 오래된 혈당으로 재분류하지 않는다.
- 관찰 길이는 기존 설정(식사·간식 4시간, 처치 2시간, 술 12시간)을 사용한다. 이는 제품의 관찰 범위이며 약물·음식 효과 시간을 의미하지 않는다.
- 기록 시각과 같거나 앞선 가장 가까운 15분 슬롯을 직전 값으로 사용한다. 기본 허용 시차는 15분이다. 최신 슬롯이 결측·경계이면 더 오래된 값으로 대체하지 않는다.
- 이후 구간은 `(기록 시각, 관찰 종료]`다. 직전 값을 이후 최고에 중복 포함하지 않는다. 자정이 넘어도 다음 날 값을 조회하며 기록 시작일에만 귀속한다.
- 정상적으로 읽힌 슬롯만 수치 통계에 사용한다. MISSING·상하단 경계·중복 시각은 제외하고 이유와 개수를 표시한다. 미래 시각의 값은 사용하지 않는다.
- 관찰 비율의 분모는 전체 관찰 구간의 15분 슬롯 수다. 진행 중 구간을 하루가 끝난 것처럼 처리하지 않는다. 공백은 보간하지 않는다.
- 최고는 **읽힌 값 중 최고**다. 실제 최고나 정확한 최고 시각이라고 표현하지 않는다. `peak_delta`는 읽힌 최고에서 직전 값을 뺀 차이다. 양수·음수 모두 그대로 표시한다.
- 관찰 구간이 겹치는 다른 섭취와 직전 슬롯~관찰 종료 사이의 인슐린 기록을 표시한다. 인슐린의 효과·필요 용량은 계산하지 않는다. 더 이전 투약·활동 등 기록 밖 요인은 통제하지 않았다는 한계도 유지한다.

## 주간 반복 요약의 조건

관찰 구간에 상·하단 경계 표시가 있으면 최고값과 `peak_delta`는 null로 둔다. 다른 읽힌 값의 낮은 최고를 전체 최고처럼 보여주지 않는다. 직전 값이 경계인 경우에도 전후 차이를 계산하지 않는다.

기록별 `comparable`은 관찰 종료, 신선한 직전 값, 구간 끝 값, 이후 정상값 2개 이상, 설정 기준 이상의 관찰 비율(기본 0.7), 경계·중복 없음, 다른 섭취 관찰 구간과 겹침 없음 조건으로 정한다. 이는 제품의 자료 조건이며 인과관계나 의학적 신뢰도 판정이 아니다.

동일 조합 기록이 2건 이상이면 묶음을 표시한다. 기본적으로 서로 다른 2일의 비교 가능한 관찰 2건 이상일 때만 `mean_peak_delta`, `min_peak_delta`, `max_peak_delta`를 제공한다. 부족하면 수치는 null이며 비교 자료 부족을 표시한다. 인슐린 동반 관찰은 숨기지 않고 별도 건수와 한계를 함께 보여준다. 음식의 좋고 나쁨 순위는 만들지 않는다.

응답은 `kind`, `from`, `to`, `interval_minutes`, `observations`, `repeated_foods`, `limitations`다. 각 관찰에는 원래 `intake_id`, `foods`, `context`, 시각, 수치와 근거 개수, `status`, `reason_codes`, `notes`, `comparable`, `summary`를 포함한다. 반복 묶음에는 전체·비교 가능 기록 ID와 건수, 비교 날짜 수, 분량 미상 여부, 인슐린 동반 건수를 포함해 근거를 추적할 수 있게 한다. 수정·삭제·그래프 재업로드 뒤 재조회하면 최신 기록으로 다시 계산한다.
